# SupportNova

Generative AI-powered complaint intelligence & resolution platform with dual-pipeline architecture.

## Architecture

- **Frontend**: React (Vite) + TypeScript + React Router
- **Backend**: FastAPI + SQLAlchemy + Pydantic
- **GenAI**: Gemini API (Pipeline 1)
- **Validation**: Python Rule Engine (Pipeline 2)
- **Database**: SQLite (dev), PostgreSQL (prod)

## Quick Start

### Prerequisites
- Python 3.10+
- Node.js 18+
- Gemini API key (from https://aistudio.google.com/apikey)

### Backend Setup

```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your GEMINI_API_KEY and other settings
uvicorn app.main:app --reload --port 8000
```

API docs: http://localhost:8000/docs

### Frontend Setup

```bash
cd frontend
npm install
cp .env.example .env  # or create .env with VITE_API_BASE_URL
npm run dev
```

App runs at: http://localhost:5173

## Key Design Principles

1. **Two Independent Pipelines**: Pipeline 1 (Gemini) interprets; Pipeline 2 (Python rules) validates authoritatively. Pipeline 2 never trusts Pipeline 1.

2. **Rule Matrix is Ground Truth**: Categories, departments, urgency, escalation are defined in hand-authored Rule Matrix, not generated by AI.

3. **Untrusted Input Isolation**: Complaint text and documents are always delimited in prompts, never concatenated as instructions.

4. **Config Over Code**: Categories, departments, rules, thresholds live in config/DB — adding a category requires no code changes.

5. **Audit Trail**: Original AI output, rule output, and any human override are all retained.

## API Endpoints

| Endpoint | Description |
|----------|-------------|
| `POST /api/complaints` | Submit new complaint |
| `GET /api/complaints/{id}` | Get complaint details |
| `POST /api/complaints/{id}/analyze` | Run Pipeline 1 (Gemini) |
| `POST /api/complaints/{id}/validate` | Run Pipeline 2 (Python) |
| `GET /api/review/queue` | Manual review queue |
| `POST /api/review/{id}/action` | Reviewer action |
| `GET /api/dashboard/stats` | Dashboard statistics |
| `POST /api/reports/export` | Export reports |

## Environment Variables

### Backend (`.env`)
```
GEMINI_API_KEY=your_key_here
GEMINI_MODEL=gemini-1.5-pro
DATABASE_URL=sqlite:///./supportnova.db
SECRET_KEY=your_secret_key
FRONTEND_ORIGIN=http://localhost:5173
```

### Frontend (`.env`)
```
VITE_API_BASE_URL=http://localhost:8000
```

## Deployment

- **Backend**: Render or Railway (set env vars in platform dashboard)
- **Frontend**: Vercel or Netlify (set `VITE_API_BASE_URL` to deployed backend URL)
- Update FastAPI CORS `allow_origins` to include production frontend URL
